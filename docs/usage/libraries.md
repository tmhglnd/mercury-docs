# 📚 External Libraries

Besides using the default synths in Mercury it is also possible to extend Mercury with your own synths or download external libraries made by others.

## Mercury-nn 

*Made by Lina Bautista*

A series of synthesizers for the Mercury live coding environment (Mercury for Max only) to manipulate neural audio networks in real time. This project uses `nn~` to load a RAVE model and exposes its first four latent dimensions for manipulation.

- **https://codeberg.org/linalab/mercury-nn**
